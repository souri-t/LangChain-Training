# テキスト差分比較ツール

Streamlitを使用した、2つのテキスト間の差分を視覚的に比較するWebアプリケーションです。
diff-match-patchライブラリを使用して、テキストの追加・削除・変更を色付けして表示します。

## 機能

- 📝 2つのテキストを並べて入力
- 🔍 diff-match-patchによる高精度な差分検出
- 🎨 色付きで差分を視覚的に表示
  - 🔴 **赤色（取り消し線）**: 削除された部分
  - 🟢 **緑色**: 追加された部分
  - ⚪ **通常表示**: 変更がない部分
- 📊 差分の統計情報を表示（削除数、追加数、変更なし）
- 📱 レスポンシブデザイン

## セットアップ

### 必要な環境

- Python 3.8以上

### インストール

1. 依存パッケージをインストール:

```bash
pip install -r requirements.txt
```

## 使い方

### アプリケーションの起動

```bash
streamlit run app.py
```

ブラウザが自動的に開きます。開かない場合は、ターミナルに表示されるURL（通常は `http://localhost:8501`）にアクセスしてください。

### 操作方法

1. **テキスト1（元の文章）** に比較元のテキストを入力
2. **テキスト2（新しい文章）** に比較先のテキストを入力
3. **差分を比較** ボタンをクリック
4. 差分結果が色付きで表示されます

### 使用例

```
テキスト1: これは元の文章です。
テキスト2: これは新しい文章です。
```

結果:
- 「元の」が赤色（削除）
- 「新しい」が緑色（追加）
- それ以外は変更なし

## 主な機能の説明

### diff-match-patchとは

Googleが開発したライブラリで、2つのテキスト間の差分を検出し、パッチの生成や適用を行うことができます。このアプリでは差分検出機能を使用しています。

### セマンティッククリーンアップ

`diff_cleanupSemantic()` を使用することで、人間が読みやすい形で差分を整理しています。

## カスタマイズ

### 色の変更

`render_diff_html()` 関数内の `background-color` を変更することで、差分の色をカスタマイズできます:

```python
# 削除: 現在 #ffcccc（薄い赤）
# 追加: 現在 #ccffcc（薄い緑）
```

### デフォルトテキストの変更

`main()` 関数内の `value` パラメータを変更することで、初期表示されるテキストを変更できます。
